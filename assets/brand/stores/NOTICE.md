# Store and launcher marks

The SVG files in this folder are copied unchanged from
[Simple Icons](https://simpleicons.org) 16.38.1, the npm package `simple-icons`
(`https://registry.npmjs.org/simple-icons/-/simple-icons-16.38.1.tgz`, checked against
the registry's sha512 integrity), file `icons/<slug>.svg`.

Simple Icons is released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
`simple-icons.json` lists no icon-specific licence for any of these marks. The marks
themselves are trademarks of their owners; showing them names the store or program a
game comes from and implies no endorsement of Irori. Following Simple Icons' disclaimer
and the brands' guidelines, Irori draws each mark whole and unaltered, in one colour (the
theme's text colour), at the size of an icon.

brand owner's request) or never did: Xbox, Amazon / Prime Gaming, ZOOM Platform (Simple

To update: download the `simple-icons` package from npm or the official
`simple-icons/simple-icons` repository only, check that each slug is still in its
`simple-icons.json`, copy the file unchanged and update the version above. Remove a mark
the package no longer contains.
