## A queue you control

Irori downloads one game at a time, in parallel chunks that are verified as they arrive. Reorder
the queue, pause, resume or cancel, and watch the speed and time left. The queue is saved, so a
download that was running carries on after a restart, and downloads pause by themselves when you
go offline and resume when you’re back. A history keeps what finished.

## Updates, all on one page

The Updates page gathers game updates and everything Irori manages: Wine and Proton builds, DXVK,
VKD3D-Proton, DXVK-NVAPI, umu, the anticheat runtimes, emulators, RetroArch cores and Irori
itself. Check now, update everything, skip a version, stop updating a game, or go back to the
Wine build an update replaced. Game updates fetch only what changed.

Automatic updates can keep to the hours you set and, where the system can tell, stay off metered
connections. A store whose update check failed keeps its last answer instead of showing nothing.

## Repair, move and import

Repair checks every file of a game against the store’s manifest and downloads what is missing or
damaged. Games can move to another drive, and installs you already have, from another launcher
or a folder of GOG installers, can be imported instead of downloaded again.

## New versions of Irori

Irori looks for its own new versions only where nothing else updates it. Installed with apt, dnf,
pacman or Flatpak, it never checks: your system updates it. Installed with Homebrew or Scoop, it
tells you the command to run. Irori never downloads or installs itself.
