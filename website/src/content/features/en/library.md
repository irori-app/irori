## Everything in one place

Irori gathers your **Epic Games**, **GOG**, **Amazon Games**, **ZOOM Platform** and **itch.io**
libraries, your installed **Steam** games, your emulated games and anything you add yourself
into one library. Games from Battle.net, the EA app, Ubisoft Connect and the Rockstar Games
Launcher join it too, once you set those launchers up.

Each game keeps one page with its playtime, last session, settings, art and logs, whichever store
it came from.

## Find any game in a second

Search is fuzzy, so “moth carto” finds *The Moth Cartographer*. Filters narrow the library to one
store, to emulated games or to what is installed, and sorting puts it in the order you want.
The command palette (<kbd>Ctrl</kbd> <kbd>K</kbd>, <kbd>Cmd</kbd> <kbd>K</kbd> on a Mac) goes
further: it finds games and actions, so you can play, install or open a setting without touching
the mouse.

## Your own games, your own art

Add any program as a game: a native app, a Windows game run through Wine, or a browser game.
Added games keep their own description, developer, release date and genres, and you can change
the title or the art of any game in the library.

## Built for big libraries

Every long list in Irori is virtualized, so only the covers on screen exist at any moment. Cover
art is decoded once into thumbnails on disk and held in a bounded GPU cache, so scrolling through
thousands of games stays smooth and memory stays flat.
