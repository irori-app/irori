On macOS, use <kbd>Cmd</kbd> wherever this page says <kbd>Ctrl</kbd>. Every action also has a
button, a menu entry and a line in the command palette.

## Everywhere

| Shortcut | Action |
| --- | --- |
| <kbd>Ctrl</kbd> <kbd>K</kbd> or <kbd>Ctrl</kbd> <kbd>P</kbd> | Open the command palette |
| <kbd>Ctrl</kbd> <kbd>1</kbd> | Library |
| <kbd>Ctrl</kbd> <kbd>2</kbd> | Downloads |
| <kbd>Ctrl</kbd> <kbd>3</kbd> | Stores |
| <kbd>Ctrl</kbd> <kbd>4</kbd> | Wine manager |
| <kbd>Ctrl</kbd> <kbd>5</kbd> | Accounts |
| <kbd>Ctrl</kbd> <kbd>6</kbd> | Stats |
| <kbd>Ctrl</kbd> <kbd>7</kbd> | Emulators |
| <kbd>Ctrl</kbd> <kbd>,</kbd> | Settings |
| <kbd>Ctrl</kbd> <kbd>R</kbd> or <kbd>F5</kbd> | Refresh the library |
| <kbd>Ctrl</kbd> <kbd>B</kbd> | Show or hide the sidebar |
| <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>B</kbd> | Big Picture |
| <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>G</kbd> | Pick a random game |
| <kbd>Alt</kbd> <kbd>←</kbd> and <kbd>Alt</kbd> <kbd>→</kbd> | Back and forward |
| <kbd>F11</kbd> | Fullscreen |
| <kbd>Ctrl</kbd> <kbd>Q</kbd> | Quit |

## macOS extras

| Shortcut | Action |
| --- | --- |
| <kbd>Cmd</kbd> <kbd>[</kbd> and <kbd>Cmd</kbd> <kbd>]</kbd> | Back and forward |
| <kbd>Ctrl</kbd> <kbd>Cmd</kbd> <kbd>F</kbd> | Fullscreen |

macOS also gets a native menu bar with the same commands.

## Big Picture

Big Picture works with a controller and with the keyboard, so every screen is reachable with the
arrow keys, <kbd>Enter</kbd> and <kbd>Escape</kbd>.

| Key | Action |
| --- | --- |
| Arrow keys | Move |
| <kbd>Enter</kbd> | Open a game’s details |
| <kbd>Space</kbd> | Play |
| <kbd>M</kbd> | Menu |
| <kbd>Esc</kbd> | Back, or leave Big Picture |

On a controller, the Guide button opens and closes Big Picture from anywhere in Irori.
